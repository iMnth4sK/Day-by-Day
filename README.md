# **Day By Day**

A 2D life simulation game about growing up, emotions and personal experiences.

## Overview

Day by Day is a open-ended life simulator focused on emotional progression, personality development and evolving social relationships.

The player experiences different stages of life - from childhood to adulthood - while interacting with systems that react dynamically to choices, habits and emotional states.

There are no mandatory objectives, fail states or competitive mechanics

The game is designed around freedom, continuity and natural progression.

## Core Features

- Emotional state system
- Personality traits shaped by player behavior
- Dynamic social relationships
- Memory-based interactions and dialogue
- Life progression through different age phases
- Open-ended gameplayer with no fixed ending

### Current Status

The project is currently in active early development

Systems are being reworked and expandes as the core gameplay loop evolves

## Technologies

Engine: Godot
Genre : Life Simulation / Sandbox

# Design Philosophy

Day by Day focuses on creating a reactive world where progression emerges naturally from the player's experiences.

Instead of rewarding performance, the game values participation, experimentation and emotional continuity.
